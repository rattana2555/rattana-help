# RATTANA HELP v2.1

ศูนย์กลางแสดงข้อมูลและติดตามการส่งต่อความช่วยเหลือผู้ประสบภัยน้ำท่วม โดยรัตนไพบูลย์

> แอปนี้ **ไม่ใช่ร้านค้า** — ไม่มีตะกร้าสินค้า, Checkout, ระบบชำระเงิน หรือการสั่งซื้อในแอป
> การสั่งซื้อ/การสนับสนุนเกิดขึ้นผ่านช่องทางภายนอกของรัตนไพบูลย์เท่านั้น (LINE OA `@RPBSALE` ตั้งค่าใน `public/assets/js/config.js` → `lineOa`)

## เริ่มใช้งาน

ต้องการ **Node.js 22.13 ขึ้นไป** (ใช้ SQLite ที่มากับ Node — ไม่ต้อง `npm install`)

```bash
npm start
```

- หน้าเว็บไซต์: http://localhost:3000
- ระบบ Admin: http://localhost:3000/admin

ครั้งแรกที่รัน ระบบจะสร้างฐานข้อมูล `data/rattana-help.db`, ใส่ข้อมูล 77 จังหวัด, ข้อมูลตัวอย่าง 3 รอบ / 8 จุด
และบัญชีผู้ดูแล `admin` พร้อมรหัสผ่านสุ่มไว้ในไฟล์ `data/ADMIN_CREDENTIALS.txt`
→ เข้าสู่ระบบ แล้วเปลี่ยนรหัสผ่านที่แท็บ “ผู้ดูแลระบบ” จากนั้นลบไฟล์นั้นทิ้ง

| คำสั่ง | ผล |
|---|---|
| `npm start` | เปิดเซิร์ฟเวอร์ (พอร์ต `PORT`, ค่าเริ่มต้น 3000) |
| `npm run reset` | ล้างฐานข้อมูล แล้วสร้างใหม่พร้อมข้อมูลตัวอย่าง |
| `npm run backup` | สำรองฐานข้อมูล + ภาพทั้งหมดไปที่ `backups/<วันเวลา>/` |
| `npm run reset:empty` | ล้างฐานข้อมูล แล้วสร้างใหม่ **ไม่มี** ข้อมูลตัวอย่าง (ใช้ก่อนเปิดใช้งานจริง) |

ตัวแปรสภาพแวดล้อม: `PORT`, `HOST`, `ADMIN_PASSWORD` (กำหนดรหัสผ่าน admin ครั้งแรกเอง), `SEED_DEMO=0` (ไม่ใส่ข้อมูลตัวอย่าง), `DB_FILE`

## ระบบ Admin (`/admin`)

แยกจากหน้าเว็บไซต์ ต้องเข้าสู่ระบบ บัญชีมี 2 ระดับ:

| | ผู้ดูแลหลัก | ทีมภาคสนาม |
|---|---|---|
| อัปโหลดภาพ ตั้งภาพปก | ✓ | ✓ |
| แก้ / ลบภาพ | ทุกภาพ | เฉพาะภาพที่ตัวเองอัปโหลด |
| เปลี่ยนสถานะ ปักพิกัด GPS อัปเดตไทม์ไลน์ | ✓ | ✓ |
| เพิ่ม / แก้ข้อมูลหลักของจุด รายการสิ่งของ ลบจุด | ✓ | – |
| โครงการ จังหวัด/พื้นที่ บัญชีทีม | ✓ | – |

สิทธิ์ถูกตรวจที่เซิร์ฟเวอร์ทุกคำขอ (ไม่ใช่แค่ซ่อนปุ่ม) · บันทึกว่าใครอัปโหลดภาพไหน (ไม่แสดงบนหน้าเว็บสาธารณะ)

## โครงสร้าง

```
server.js        HTTP server + REST API (public + admin)
db.js            Schema, 77 จังหวัด, ข้อมูลตัวอย่าง, รหัสผ่าน (scrypt)
public/
  index.html     เว็บไซต์ (SPA, hash routing)
  admin.html     ระบบ Admin
  assets/js/     config.js · common.js · app.js · admin.js
  assets/css/    style.css · admin.css
data/            ฐานข้อมูล SQLite (ไม่ commit)
uploads/         ภาพที่อัปโหลด (ไม่ commit)
```

ตารางในฐานข้อมูล: `relief_projects`, `relief_locations`, `relief_items`, `relief_photos`, `relief_updates`,
`provinces`, `districts`, `subdistricts`, `admins` (+ `admin_sessions`)
ความสัมพันธ์: 1 Project → หลาย Locations · 1 Location → หลาย Items / Photos / Updates

## ตั้งค่า (`public/assets/js/config.js`)

- `dateEra` — `'BE'` (ค่าเริ่มต้น) แสดง 03/10/2569 หรือ `'CE'` แสดง 03/10/2026
- `lineOa` — LINE Official Account สำหรับผู้สนับสนุน (ตั้งไว้: `https://lin.ee/XQHHq7M` · `@RPBSALE`) แสดงปุ่มที่หน้าแรก ปุ่มลอย หน้ารายละเอียด การ์ดบนแผนที่ และ footer — เว้น `url` ว่างเพื่อซ่อน
- `supportUrl` / `supportLabel` — ลิงก์ช่องทางสนับสนุนภายนอก (ว่าง = ซ่อนปุ่ม)
- `tileUrl` — แผนที่ใช้ OpenStreetMap (เหมาะกับปริมาณผู้ชมไม่สูง) หากผู้ชมจำนวนมากควรเปลี่ยนเป็นผู้ให้บริการที่มี API key
  และเพิ่มโดเมนใน `img-src` ของ `PAGE_CSP` ใน `server.js`

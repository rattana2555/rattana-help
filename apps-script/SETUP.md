# ตั้งค่าระบบข้อมูล (Google Sheets + Google Drive) — ทำครั้งเดียว ~10 นาที

หน้าเว็บ RATTANA HELP อยู่บน GitHub Pages (ฟรี) ส่วนข้อมูลเก็บใน Google Sheets และภาพเก็บใน Google Drive
ผ่าน Apps Script ซึ่งทำหน้าที่เป็นหลังบ้าน (ตรวจรหัสผ่าน ตรวจสิทธิ์ บันทึกข้อมูล) — ไม่มีค่าใช้จ่าย

## 1. สร้าง Google Sheet และวางโค้ด

1. เปิด [sheets.new](https://sheets.new) ด้วยบัญชี Google ที่จะเป็นเจ้าของข้อมูล ตั้งชื่อ เช่น `RATTANA HELP — ข้อมูล`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](Code.gs) ใน repo นี้ → กด 💾 บันทึก

## 2. รัน setup ครั้งแรก

1. ด้านบนเลือกฟังก์ชัน **setup** แล้วกด **▶ เรียกใช้ (Run)**
2. Google จะขออนุญาต → **ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โปรเจกต์ (ไม่ปลอดภัย) → อนุญาต**
   (ขึ้นคำว่าไม่ปลอดภัยเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ส่งให้ Google ตรวจ)
3. ดู **บันทึกการดำเนินการ (Execution log)** ด้านล่าง จะมีบรรทัด
   `First admin → username: admin · password: ……` — จดรหัสผ่านนี้ไว้ (เข้าระบบแล้วเปลี่ยนทันที)

setup จะสร้างแผ่นงาน 9 แผ่น (projects, locations, items, photos, updates, provinces, districts, subdistricts, admins)
ใส่ 77 จังหวัด และสร้างโฟลเดอร์ Drive “RATTANA HELP — ภาพการช่วยเหลือ”

> ห้ามแก้ไข/เรียงลำดับข้อมูลในแผ่นงานด้วยมือ ให้แก้ผ่านหน้า Admin เท่านั้น (แผ่น `admins` เก็บรหัสผ่านแบบเข้ารหัส — อย่าแชร์ไฟล์ Sheet นี้ให้คนนอก)

## 3. Deploy เป็น Web app

1. ปุ่ม **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. ไอคอนเฟือง → เลือก **เว็บแอป (Web app)**
3. **เรียกใช้ในฐานะ (Execute as): ฉัน (Me)** · **ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)**
4. กด Deploy → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

“ทุกคน” หมายถึงหน้าเว็บสาธารณะอ่านข้อมูลที่เผยแพร่ได้ — การเพิ่ม/แก้/ลบ ทุกครั้งต้องล็อกอินและผ่านการตรวจสิทธิ์ในสคริปต์

## 4. ใส่ URL ในเว็บ

แก้ไฟล์ `docs/assets/js/config.js`:

```js
apiUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

แล้ว commit + push ขึ้น GitHub (หรือส่ง URL ให้ทีมพัฒนาใส่ให้)

## อัปเดตโค้ด Apps Script ภายหลัง

> ต้องทำทุกครั้งที่ไฟล์ `Code.gs` ใน repo เปลี่ยน (หน้า Admin จะขึ้นแถบเตือนสีแดงถ้าโค้ดใน Google ยังเป็นเวอร์ชันเก่า)
> ระบบจะเพิ่มคอลัมน์ใหม่ในชีทให้เอง ข้อมูลเดิมไม่หาย

วางโค้ดใหม่ → บันทึก → **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → ✏️ แก้ไข → เวอร์ชัน: ใหม่ → Deploy**
(URL เดิมใช้ต่อได้ ไม่ต้องแก้ config.js)

## ลืมรหัสผ่าน admin

เปิด Apps Script → เลือกฟังก์ชัน **resetAdminPassword** → ▶ Run → รหัสใหม่อยู่ใน Execution log (ไม่ต้อง Deploy ใหม่)

## ข้อควรรู้

- **บัญชีองค์กร (Google Workspace):** ถ้าโดเมนปิดการแชร์ไฟล์แบบ “ทุกคนที่มีลิงก์” ภาพจะอัปโหลดไม่ได้ (ระบบจะแจ้งเตือน)
  → ให้ผู้ดูแล Workspace เปิดสิทธิ์ หรือ deploy ด้วยบัญชี Gmail ทั่วไป
- **สำรองข้อมูล:** ไฟล์ → ทำสำเนา (Sheet) และโฟลเดอร์ภาพใน Drive · Google เก็บประวัติการแก้ไขให้อัตโนมัติ
- **ความจุ:** ภาพใช้พื้นที่ Google Drive ของบัญชีเจ้าของ (บัญชีฟรี 15 GB ≈ 30,000 ภาพ)
- หน้าเว็บสาธารณะอัปเดตข้อมูลภายใน ~5 นาที (มีแคช) · หน้า Admin เห็นทันที
